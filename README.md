# DemoVideoScript-GuiAssert

DemoVideoScript backend adapter that runs scenarios on graphical windows through GuiAssert's vision and OS-level input.

> **Status:** ☐ Planned — design stage; no implementation yet.

Implements the [DemoVideoScript](https://github.com/metacraft-labs/DemoVideoScript)
backend protocol in-process over the public API of
[GuiAssert](https://github.com/metacraft-labs/GuiAssert): page objects located by OCR and
layout detection, input delivered as OS-level events, recordings as video. Also carries the
vision binding of the DemoVideoScript conformance application.
